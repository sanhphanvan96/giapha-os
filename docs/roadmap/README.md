# Roadmap

Thư mục này chứa các plan phát triển và cải tiến cho GiaPha-OS.

## Quy ước đặt tên

```
NNN-short-slug.md
```

- `NNN` — số thứ tự 3 chữ số (001, 002, ...)
- `short-slug` — mô tả ngắn bằng tiếng Anh, dùng dấu gạch ngang

## Trạng thái plan

| Ký hiệu | Ý nghĩa |
|---------|---------|
| `[ ]` | Chưa làm |
| `[~]` | Đang làm |
| `[x]` | Hoàn thành |
| `[-]` | Bỏ qua / không làm |
